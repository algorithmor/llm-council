Or import from Google Takeout

No API key or public subscriptions needed. In Google Takeout, export only YouTube and YouTube Music → subscriptions, then upload the subscriptions.csv from the archive.

Getting an API key (5 minutes, free)

  1. Open the Google Cloud Console and create a project (any name).
  2. Go to APIs & Services → Library → YouTube Data API v3 and click Enable.
  3. Go to Credentials → Create credentials → API key. Optionally restrict it to the YouTube Data API v3.
  4. Paste the key above.

Making your subscriptions visible to the key

An API key can only read public subscription lists. On YouTube, open Settings → Privacy and switch off “Keep all my subscriptions private”.

Prefer to keep them private? Use the Google Takeout import above, or add channels by hand in the Reader (paste any channel URL; DailyBee shows every YouTube channel feed in the bulletin).

How much quota does this use?

Very little. New videos come from each channel's free public RSS feed, so the API is used only to list your subscriptions (1 unit per 50 channels, once a day) and to look up video lengths (1 unit per 50 videos). The free daily quota is 10,000 units.
